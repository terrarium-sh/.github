# <img src="favicon.svg" alt="" height="32"> Terrarium

Tools for giving coding agents room to work—without giving them your whole machine.

Open-source tools for running coding agents and development environments with clear, explicit boundaries around what they can access.

## Projects

- [**terrarium**](https://github.com/terrarium-sh/terrarium) — Terra, a sandbox for coding agents and development tools.
- [**terrarium_examples**](https://github.com/terrarium-sh/terrarium_examples) — Official and community examples for Terra.

## Our approach

We believe agent environments should be simple to understand, easy to inspect, and explicit about their access to your files and network.

Terrarium keeps the core small. Configuration and external tools add flexibility without making the foundation harder to audit.
